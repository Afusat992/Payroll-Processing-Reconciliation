## Project Overview

This portfolio demonstrates the organization, summarization and reconciliation of payroll transactions for a fictional business with six employees.

The project includes an employee payroll summary, underlying transaction records and a reconciliation control that compares payroll totals across both schedules.

## Project Scope

The source report contains 12 payroll transactions covering regular pay, bonuses and overtime.

I organized the transactions into an employee payroll summary and checked that gross pay and net pay totals agree with the source transaction register.

The schedules also show illustrative PAYE, pension and other deductions.

## Reconciliation Results

| Measure | Amount |
|---|---:|
| Employees | 6 |

| Pension Deductions | $2,060 |
| Other Deductions | $380 |
| Total Deductions | $5,015 |
| Total Net Pay | $20,735 |

| Net Pay Reconciliation Difference | $0.00 |

The reconciliation confirms that the employee payroll summary agrees with the source transaction register.

A zero reconciliation difference demonstrates agreement between the two schedules. It does not independently establish statutory payroll compliance.
